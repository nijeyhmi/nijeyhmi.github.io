왜 $reset을 쓰면 반응성이 사라질까

2022. 06. 21
  • Vue 
store.$reset = function $reset() {
    const newState = state ? state() : {}
    // we use a patch to group all changes into one single subscription
    this.$patch(($state) => {
      assign($state, newState)
    })
  }

변경된 state를 assign() 메서드를 통해 새로 할당

→ object의 저장소 주소는 그대로, value의 주소값만 바뀌어 들어가기 때문인가?

reset을 사용하면 반응성을 잃는다

https://github.com/vuejs/pinia/issues/593

Reset only calls the function to create a new object. If possible, build the object inside of the state method

https://github.com/vuejs/pinia/issues/484

state 메서드 안에서 가급적 해결할 것…

https://michaelnthiessen.com/force-re-render/

$forceUpdate()나 key를 사용해서 vue를 re-render하는 방법도 있다.
