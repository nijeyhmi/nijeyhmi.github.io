코드 리뷰가 왜 필요한가

저맥락자 → 고맥락자로 만들기 위해

  • 내가 휴가를 얼마나 편하게 갈 수 있느냐
  • 휴가를 갈 때 노트북을 두고 갈 수 있느냐
  • 저맥락자: 코드를 큰 맥락에서 이해하지 못 하는 사람

→ 저맥락자와 고맥락자의 코드 리뷰는 다르다

코드 조각만 보고 하는 리뷰를 반복하면서 고맥락자로 나아가야 함

맥락에 기반해서 리뷰를 해야 한다는 것

집단이 공유한 정보가 그 집단의 IQ

일관적인 코드 스타일을 유지하는 장치

  • 모듈을 구성하는 방법이나 코드를 구성하는 스타일이 일관적이어야 이해가 쉬움

코드 리뷰를 효율적으로 할 수 있는 방법

가독성 위원회

https://frontend-fundamentals.com/code-quality/

  • 코드의 가독성을 논의하기 위한 위원회
  • 코드가 잘못된 근본적 이유를 탐구

→ 좋은 코드의 평가 기준을 맞추기

좋은 코드의 기준

  • 가독성
  • 결합도
  • 응집도
  • 예측가능성

코드 스멜 워킹그룹

  • 좋은 코드에 대해서 이야기하는 것도 좋지만 나쁜 코드에 대해 이야기할 장소도 필요하다
  • 4명이 주에 하나씩 패턴을 수집해옴→ 소통 비용을 줄이기 위해

→ 고쳐야 할 코드의 싱크가 맞도록 하는 것을 기대

이를 위해서는 집단이 쓰는 용어나 멘탈 모델이 비슷해야 함

회사에서 논의를 잘 하고 지식을 잘 남겨놓자

  • 가장 먼저 리뷰 기반 개선이 일어나는 팀
  • 구성원이 골고루 참여하는 팀
